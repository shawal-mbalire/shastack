## Overview

shastack is a workspace-first meta-framework that unifies Web, Mobile, Research, ML, and Embedded systems under a single CLI and justfile orchestration layer.

### Core Philosophy

- **Unified Tooling**: One command (`sha`) for everything
- **Modular Initialization**: Toggle features during or after workspace creation
- **Flat Monorepo**: Domain-specific top-level folders
- **Just-Driven**: Complex automation in justfiles
- **Code-First API**: Zod/Pydantic definitions with auto-generated clients
- **Unified Secrets**: envchain-backed keychain storage
